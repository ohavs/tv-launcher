## תקציב ביצועים (כדי שלא ייתקע)
- מעבד חלש (4 ליבות A55), 4GB RAM, ~1.4GB פנוי כשאפליקציה פתוחה; Stremio (עם שרת node) לוקח 300–600MB.
- TV Home UI ≤ 150MB · שירות רקע (נגישות + שרת לטלפון) ≤ 30MB ובלי CPU כשאין פעילות.
- בלי polling — רק אירועים. בלי אנימציות רציפות מחוץ לפוקוס (לשקול לכבות את ה-sway).
- רכיבים כבדים (מצלמות) — בתהליך נפרד, רק כשפתוחים. עד 2 זרמי וידאו במקביל.
- כל פיצ'ר כבד ניתן לכיבוי מההגדרות.

## ארכיטקטורה
```
phone app (Android, Kotlin/Compose)
  ├─ Android TV Remote v2 (TLS, protobuf) ──► שירות השלט המובנה בטלוויזיה  → כל המקשים/טקסט/ווליום
  └─ WebSocket (JSON, NSD _tvhome._tcp, צימוד PIN) ──► TV Home CompanionServer
                                                        (רץ בתהליך של HomeKeyService — תמיד חי)
TV Home: launcher UI · HomeKeyService (מקשים + אוטומציה) · CompanionServer · Camera panel (תהליך נפרד)
repo: app/ (TV) · phone/ (טלפון) · shared/ (מודלים של הפרוטוקול)
CI: release אחד עם שני assets: tv-home.apk + tv-remote.apk; כל אפליקציה בודקת עדכונים ל-asset שלה.
```

## שלבים

### ✅ שלב 0 — כפתור Google Home בשלט (v1.0.5)

### ✅ שלב L1 — עיצוב חדש + דשבורד (v1.0.7)
- השראה: Plume Launcher. שורות: דשבורד (שעה/תאריך/מזג אוויר, מתנגן עכשיו + play/pause, הבית החכם, כפתורי כל האפליקציות/הגדרות)
  → שורת אפליקציות (לוגו על זכוכית, מתמלא בצבע האפליקציה בפוקוס) → תוכן מהאפליקציה בפוקוס.
- "כל האפליקציות" (גריד + סידור), סגנון אריחים (אייקונים/מונוכרום/באנרים), עיר למזג אוויר, הנפשת כניסה + זום מהאריח בפתיחה.

### ✅ שלב L2 — מצלמות DVR בדשבורד (v1.0.8–1.0.10)
- 8 ערוצים ב-DVR (TVT/Provision). דשבורד: 2 מצלמות חיות + "כל המצלמות" (גריד של 8) → OK = מסך מלא, Back = הביתה.
- בנוסף (בקשת המשתמש): Google Home הוסתר; סגנון "עגולים" במקום אייקונים/מונוכרום; פריסה "קולנועית".

### ⬜ שלב L2b (אופציונלי) — דשבורד "חכם"
- נתונים מ-Google Home (מכשירים/סצנות) במקום הכרטיס שהוסתר; סדר כרטיסים לפי הקשר (מתנגן עכשיו ראשון, תנועה במצלמה).

### ⬜ שלב L3 — Imilab EC5 דרך go2rtc
- בינארי go2rtc (arm) בתוך ה-APK, מופעל רק כשכרטיס המצלמה גלוי; **ידני:** התחברות לחשבון Xiaomi בממשק go2rtc מהטלפון.
- כרטיס בדשבורד כמו ב-L2 (RTSP מקומי מ-go2rtc).

### ⬜ שלב L4 — YouTube TV בלי פרסומות
- Activity עם WebView בתהליך נפרד: `youtube.com/tv`, UA של Cobalt, מיפוי מקשי שלט, סינון `adPlacements`/`playerAds`; אופציונלי SponsorBlock.
- התחברות: קוד ב-`youtube.com/activate` (סיסמה לא עוברת בקוד שלנו). כפתור YouTube בשלט → אליו (ניתן לכיבוי).
- **גמור =** צפייה בחשבון שלך בלי פרסומות, שלט עובד מלא.

### ⬜ שלב 1 — monorepo + שלד אפליקציית טלפון
- מודולים `phone/`, `shared/`; CI בונה שני APK ומעלה ל-release אחד; updater של כל אפליקציה בוחר asset לפי שם.
- אפליקציית טלפון: מסך ריק + הגדרות עם "בדוק עדכונים" (כולל הרשאת התקנה ממקורות לא ידועים).
- **גמור =** שתי האפליקציות מתעדכנות מ-GitHub. **ידני:** התקנה ראשונה של ה-APK בטלפון (לינק אחד).

### ⬜ שלב 2 — שלט בטלפון (Android TV Remote v2)
- צימוד (קוד מוצג בטלוויזיה), D-pad + swipe pad, OK/חזור/בית/לחיצה ארוכה, מדיה, הפעלה, מקלדת (שליחת טקסט).
- כפתורי ווליום של הטלפון → מקשי ווליום; בדיקת CEC volume (`hdmi_control_volume_control_enabled`) ודיווח.
- התראה קבועה עם שלט מיני + Quick Settings tile (אופציונלי).
- **גמור =** אפשר לשלוט בטלוויזיה רק מהטלפון, השהיה < 100ms.

### ⬜ שלב 3 — קישור TV Home ↔ טלפון
- CompanionServer (Java-WebSocket, קטן) בתוך תהליך HomeKeyService; פרסום NSD; צימוד עם PIN שמוצג בטלוויזיה; token.
- אירועים מהטלוויזיה: אפליקציה פעילה, מה מתנגן (MediaSession), מצב ווליום אם יש.
- **גמור =** הטלפון מציג "עכשיו בטלוויזיה: Stremio — שם הפרק".

### ⬜ שלב 4 — Delay כתוביות ב-Stremio
- spike בזמן ניגון אמיתי (**ידני:** להפעיל פרק): קיצורי מקשים → אם אין, dump של עץ הנגישות של תפריט הכתוביות → בחירת שיטה.
- כרטיס בטלפון שמופיע רק כש-Stremio מנגן: ‎−1s / −0.1s / +0.1s / +1s / איפוס + הערך הנוכחי.
- **גמור =** שינוי delay בפרק אמיתי בלי לגעת בשלט, תגובה < 0.5s.

### ⬜ שלב 5 — ווליום מתקדם
- מצב לילה (כפתור/שעה: הורדה N צעדים או השתקה), תקרה רק אם הטלוויזיה מדווחת רמה ב-CEC.

### ⬜ שלב 6 — שדרוג הלאנצ'ר I
- Control Center (פאנל צד): טיימר שינה, רקע הבא (Google Home/מצלמה/מתנגן כבר בדשבורד).

- רקעים: תדירות + העלאת תמונות מהטלפון. סידור/הסתרת אפליקציות מהטלפון.
- מצב "שקט" לאנימציות (בלי sway) לחיסכון.
